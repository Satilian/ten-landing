# Заявки на ремонт

Форма отправляет заявки на почту через Web3Forms без собственного сервера.

1. Создайте Access Key на https://web3forms.com/ для почты получателя и подтвердите email.
2. Предоставленный публичный ключ уже добавлен в `src/App.tsx`: он работает в preview и production без дополнительной настройки окружения. Для смены получателя можно заменить ключ или задать `VITE_WEB3FORMS_ACCESS_KEY=ваш-ключ` в `.env.local`.
3. При использовании переменной для production задайте её в окружении сборки и пересоберите сайт. Vite встраивает её в клиентский код; ключ Web3Forms предназначен для публичного использования.
4. Отправьте тестовую заявку из браузера и проверьте входящие письма и спам.

Без ключа форма сообщает о недоступности отправки и сохраняет поля. Успех отображается только после успешного ответа API. При ошибке или таймауте поля сохраняются. Повторные нажатия заблокированы во время запроса. Скрытое поле `botcheck` передаётся сервису для защиты от простых ботов.
